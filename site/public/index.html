How it works

One request instead of a retry loop

Git assumes every client keeps a full copy and works offline. Agents are always online and land small changes, many at once. Graft keeps history on the server and does the merge work where the data already is.

01 · READ

Read at an exact revision

Agents list, search and read files over MCP. Every answer names the changeset it came from. Nothing is cloned.

graft_read_file path="app.js"
@ 3f9c1e0a2b77 app.js
02 · SEND

Send the change and its base

One call carries the revision the agent read and its edits: whole files, exact string replacements, moves or deletes.

graft_commit base="3f9c1e0a2b77"
  edits: "// routes" → "…"
03 · LAND

The server lands it

If main moved, the server rebases the change in memory with a three-way merge and swaps the branch pointer. Only a real textual conflict comes back.

Landed on main: 8be21c… 
(auto-rebased from 51aa9e…)
What's in the box

Everything an agent team needs

One container for the server. One file for the MCP plugin. A CLI for agents that need real files to run tests.

MCP plugin

13 tools for Claude Code and any MCP client: read, search, find, commit-and-land, diff, log, blame, branches. Plus a skill that teaches the loop.

Lock-free landing

Branches move only by compare-and-swap on one row. No merge queue, no global lock. Lost races are retried on the server.

Small changesets

A commit stores only the paths it changed. Trees, blame and path history are derived from parents and cached, with checkpoints every 64 generations.

Sparse workspaces

graft clone --sparse src/ fetches only what you ask for. Every workspace on a machine shares one content-addressed cache.

Secure by default

Loopback-only until you set a token. CSRF and DNS-rebinding defenses, strict CSP, hash-verified blobs, sandboxed client paths.

Web viewer

Live history, changeset diffs, a file browser with blame, and code search for the people watching the agents.

Get started

Running in three commands

Node 22.5+ or Docker. The deployment guide covers TLS, backups, upgrades and releases.

SERVER

Start Graft

git clone https://github.com/G4G4N/graft && cd graft
export GRAFT_TOKEN=$(openssl rand -hex 32)
docker compose up -d --build
curl -s localhost:7070/api/version
AGENTS

Connect Claude Code

claude plugin marketplace add ./graft
claude plugin install graft@graft
export GRAFT_URL=https://graft.example.com
FILES

Workspaces for tests

graft clone app work --sparse src
# edit, run tests…
graft commit -m "Fix the router"
